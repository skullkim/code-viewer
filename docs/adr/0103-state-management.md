# ADR-0103: 상태 관리 — @Observable 모델 + 순수 함수로 분리한 뷰 로직

- 상태: 채택
- 영역: 프론트엔드 (frontend-senior)
- 날짜: 2026-08-29

## 맥락

엔진이 상태를 **네 개의 `AsyncStream`**으로 밀어 준다(인덱스 상태, 편집 세션 상태, 그리드 스냅샷,
에디터 상태). 화면은 02 §3이 정의한 상태들(인덱스 5상태 · 편집 세션 4상태 · 입력 모드 6표시 ·
각 패널의 빈/로딩/에러/정상)을 빠짐없이 반영해야 하고, TDD가 강제다.

Swift 6의 엄격 동시성이 걸린다 — spike에서 확인했듯 `NSFont` 같은 전역 상수조차 격리를 요구하고,
`main.swift`의 톱레벨 코드에는 글로벌 액터를 붙일 수 없다.

## 결정

- **상태 보관**: 영역별 `@MainActor @Observable` 클래스(`ProjectModel` · `EditorModel` ·
  `SearchModel` · `IndexModel`)를 `AppModel`이 합성한다. 스트림 소비는 `AppModel`이 소유한
  `Task`에서 하고, 모델 갱신은 MainActor에서만 일어난다.
- **뷰 로직은 모델 밖으로**: 화면이 무엇을 보여줄지 정하는 판단 — 상태바 구성, 레이아웃 치수,
  경로 축약·상대화, 결과의 파일별 그룹핑, 모드별 힌트, 메뉴 항목 활성 여부 — 은 전부
  **입력을 받아 값을 돌려주는 순수 함수/값 타입**으로 뺀다. 뷰와 모델은 그 결과를 표시만 한다.
- **엔트리 포인트는 톱레벨 코드를 쓰지 않는다** — `main.swift` 대신 `@main` 타입.

## 고려한 대안

- **A. `ObservableObject` + `@Published` (Combine)** — 검증된 방식이지만 macOS 14+에서는 구세대이고,
  프로퍼티 단위 추적이 없어 관련 없는 뷰까지 무효화된다. 그리드 스냅샷이 초당 수십 번 바뀌는
  이 앱에서는 실제 비용이다.
- **B. 단방향 스토어(TCA류)** — 상태 전이가 명시적이고 테스트가 좋다. 그러나 외부 의존성이 늘고
  (컨벤션: 목적당 라이브러리 하나), 화면 10개짜리 단일 창 앱에는 복잡도 예산 초과다.
- **C. `@Observable` + 순수 함수 분리 (채택)**

## 트레이드오프

- **테스트 용이성**: B가 가장 좋아 보이지만, C의 "판단을 순수 함수로 뺀다"가 실질적으로 같은 것을
  준다 — **테스트하고 싶은 것은 상태 보관이 아니라 판단**이기 때문이다. 02의 상태 정의가 그대로
  테이블 테스트 케이스가 된다. 반대로 `@Observable` 클래스 자체도 평범한 클래스라 직접 테스트된다.
- **단순성**: C는 언어·프레임워크가 공식적으로 미는 기본값(Observation)이고 의존성이 0이다.
- **변경 가능성**: 변동점은 "엔진 스트림 → 화면 상태" 매핑이고, C는 그 매핑이 순수 함수라
  가장 싸게 바뀐다.
- **위임 적합성**: 주니어에게 "이 순수 함수와 그 테스트" 또는 "이 뷰 하나"를 줄 수 있다.
  모델 소유권이 시니어에 남아 경계가 흐려지지 않는다.
- **되돌림**: B로 가려면 전면 재작성이지만, C→B 이행은 순수 함수가 그대로 리듀서가 되므로
  생각보다 싸다. 반대 방향(B에서 시작해 되돌리기)이 더 비싸다.

## 채택 이유

Apple이 공식적으로 추구하는 관례(Observation)를 기본값으로 삼되, **TDD 게이트가 요구하는
테스트 표면을 프레임워크가 아니라 설계로 확보**했다. SwiftUI 뷰는 테스트하기 어렵다는 사실을
받아들이고, 검증 가치가 있는 것을 뷰 밖으로 꺼내는 쪽을 택했다.

## 파생 결과

`CodeNavigatorApp`이 executable 단일 타깃이면 테스트 타깃을 붙일 수 없다(`main` 심볼로 링크가 깨진다).
`CodeNavigatorAppKit` 라이브러리(뷰·모델·순수 로직 전부) + `CodeNavigatorApp` executable(조립 루트만)로
쪼개야 한다. Package.swift는 backend-senior 소유라 반영을 요청했다.
