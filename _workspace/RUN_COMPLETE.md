## 실측으로 잡은 결함 (테스트만으로는 안 나왔다)

1. **터미널 출력이 12글자에서 잘렸다.** 그리드 뷰가 첫 레이아웃에서 1×1 을 보고하고, 그 값이
   pty 로 가면서 libvterm 이 이미 찍힌 줄을 파괴했다. 앱에 탐침을 심어 `resize 1x1` 을 눈으로
   보고서야 알았다 — 단위 테스트는 전부 초록이었다.
2. **디버그 실행을 눌러도 서버가 안 떴다.** `suspend=y` 로 띄우고 붙기만 하고 재개하지 않았다.
   화면에 `Listening for transport` 만 있고 `PORT=` 가 없는 것으로 드러났다.
3. **셸 버튼이 조용히 아무 일도 안 했다.** 프로젝트가 없을 때 `guard … else { return }`.

## 검사기가 틀린 적 3회 (앱을 고치기 전에 갈랐다)

- `swift test --filter` 는 **표시 이름이 아니라 타입 이름**을 본다. 한글 스위트 이름으로 거르니
  새 스위트가 `0 tests ... passed` 로 보였다 — 건너뛴 것이 통과로 읽히는 모양이다.
- 접근성 `set value of text field` 는 **SwiftUI 바인딩을 건드리지 않는다.** 앱이 저장을 안 한
  것처럼 보였다. 진짜 타이핑(`keystroke`)으로 다시 재니 정상이었다.
- AppleScript `entire contents` 는 큰 창에서 **조용히 0건**을 돌려준다. 창에 버튼이 하나도
  없는 것처럼 보였다. 한 단계 얕은 질의(`UI elements of window 1`)로 5개가 나왔다.

또 한 번: `open`은 **이미 도는 인스턴스를 재사용**한다. 새로 번들하고 `open` 한 뒤 찍은
스크린샷이 옛 빌드였다. 이후로는 프로세스 시작 시각과 바이너리 mtime 을 대조하고 나서 판정했다.
