## 설계 결정

**터미널은 nvim 의 `:terminal` 을 쓴다.** 우리가 VT100 파서와 PTY 를 직접 쓰지 않는다.
이미 nvim 을 번들하고 있고, nvim 의 터미널은 libvterm 기반의 진짜 터미널 에뮬레이터다.
UI 프로토콜도 우리가 이미 다룬다 — 그리드 렌더러·키 입력·마우스가 그대로 재사용된다.

값은 **별도 nvim 프로세스**다. 편집기와 같은 인스턴스를 쓰면 터미널 버퍼가 편집기 자리를
차지하고, 탭 전환이 서로를 밀어낸다.

터미널 nvim 은 `--clean` 으로 띄운다. 편집기는 INV-4 때문에 사용자 설정을 읽지만, 터미널은
사용자 플러그인이 키를 가로채면 셸이 안 먹는다 — 예측 가능한 쪽이 낫다.

**디버그 실행은 명령을 고쳐 쓰지 않는다.** `-agentlib:jdwp=...` 를 어디에 넣을지는
명령마다 다르다(`java` 직접 · `./gradlew bootRun` · `mvn`). 대신 **`JAVA_TOOL_OPTIONS`
환경변수**로 넣는다 — JVM 이 표준으로 읽고, 어떤 실행 방식이든 통한다.

떠 있을 때만 창 열거가 된다 · GUI 조작에도 `2>/dev/null` 을 쓰지 마라.
