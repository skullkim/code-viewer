## 0. 디자인 방향 (판단 근거)

### 0.1 이 제품이 다른 에디터 디자인과 다른 점
- **편집기 영역은 Neovim이 그린다.** 텍스트·라인 번호·구문 강조·커서·선택 영역·사용자 상태줄(lualine 등)은 전부 Neovim이 렌더한 그리드다. 앱이 디자인하고 구현하는 것은 **그 주변 셸(트리·패널·툴바·상태바·모달·팝오버)과 그 상태**다.
  - 따라서 이 문서는 "코드가 어떻게 보이는가"를 규정하지 않는다. 그것은 사용자의 `~/.config/nvim` 소유다(INV-4).
  - 프로토타입의 코드 영역은 **모사**다. 프론트는 그 자리에 Neovim 그리드 뷰를 놓고, 주변 여백·경계·크기만 맞춘다.
- **정의 이동 하이라이트도 앱이 그리지 않는다.** 앱은 Neovim에 "이 위치로 커서 이동 + 화면 중앙 정렬 + 임시 강조"를 요청하고, 그리는 주체는 Neovim이다(INV-3 정합 — 앱은 파일도 화면도 직접 쓰지 않는다).
- **앱 상태바와 Neovim 상태줄은 별개다.** 앱 상태바(창 최하단, 26px)는 앱이 소유하고, 그 위의 Neovim 상태줄은 사용자 설정이 그린다. 앱은 후자를 가로채거나 숨기지 않는다(INV-4).

### 0.4 용어 규칙
UI 문구는 01 §3 용어집의 용어만 쓴다 — **프로젝트 / 심볼 / 정의 / 참조 / 인덱스 / 편집 세션 / 더티 버퍼**. 새 용어를 만들지 않는다.

## 2. 사용자 플로우

### F-1: 프로젝트 열기 (REQ-001)
1. 앱 시작 → 프로젝트 없음이면 **W-2 빈 상태**(최근 프로젝트 목록 + [프로젝트 열기…])
2. ⌘O 또는 버튼 → **맥 표준 폴더 선택 대화상자**(AC-1)
3. 분기
   - 성공: 트리 표시(스켈레톤 → 목록) · 인덱스 칩 `없음 → 인덱싱 중(진행률)` · 편집 세션 연결 시작
   - 실패(경로 없음·권한 없음): **시트**로 "프로젝트를 열 수 없습니다 + 사유(경로/권한)" → [확인]. **이전 상태 유지**, 트리·인덱스 불변 (AC-3)
4. 전환: 툴바 프로젝트 팝업 또는 파일 ▸ 최근 프로젝트 열기 → 트리·에디터·패널·검색 결과가 모두 새 프로젝트로 리셋 (AC-2)
5. 제외 규칙 고지: 빈 상태 하단에 ".gitignore와 기본 제외 목록(node_modules · build · dist · .git · target)을 존중합니다" (AC-4)

### F-2: 파일 열기 (REQ-003)
1. 트리에서 디렉토리 클릭 → 하위 항목 **지연 로드**(펼침 아이콘 ▸→▾, 로딩 중이면 해당 노드에 스켈레톤 1~3행) (AC-1)
2. 파일 선택 → Neovim에 해당 파일 버퍼 열기 요청 → 상태바 경로·언어 갱신, 창 제목 = 파일 이름
3. 현재 파일은 트리에서 **선택 강조**(accent 배경 + 흰 글자)로 유지 (AC-3). 더티면 행 우측에 ● (REQ-004)
4. 제외 대상은 애초에 트리에 없다 (AC-2)

### F-3: 정의로 이동 (REQ-005, SC-1·2)
1. 커서를 심볼에 두고 **⌘B**(또는 사용자 매핑 `gd`) (AC-1)
2. 분기
   - 정의 1건: 해당 파일을 열고 Neovim에 커서 이동 + 화면 중앙 정렬 + 임시 라인 강조 요청 (AC-1)
   - 동명 N≥2건: **W-4 후보 팝오버**(커서 위치 앵커) — 종류 배지 + 시그니처 + 파일:라인. ↑↓ 이동 · Enter 이동 · Esc 취소 (AC-2)
   - 0건: 상태바 메시지 영역에 **`✕ '{이름}' 정의를 찾을 수 없습니다`** 3초 표시 + VoiceOver 알림. 무반응 금지 (AC-3)
3. 되돌아가기: **⌘[** 또는 Vim `⌃O` — 앱 단축키와 Vim 점프 목록이 같은 스택을 본다 (AC-4)

### F-4: 참조 보기 (REQ-006)
1. 커서를 심볼에 두고 **⇧⌘B** (또는 W-4 팝오버 하단 "이 이름의 참조 보기")
2. 우측 패널이 [참조] 탭으로 열림 → 헤더에 심볼 이름 + 건수(정의 N) + **근사 안내 배너 상시 표시** (AC-3)
3. 목록: 파일별 그룹 → 라인 번호 + 줄 미리보기(일치 부분 강조). 정의 위치 항목엔 **[정의] 배지** (AC-2)
4. 항목 선택(클릭 또는 ↑↓+Enter) → 그 위치로 이동, 선택 항목은 목록에서 강조 유지 (AC-1)
5. 분기: 0건 → "'{이름}' 참조 없음" — **배너는 그대로 유지** (AC-4)

### F-5: 심볼 퍼지 검색 (REQ-007)
1. **⌘P** 또는 툴바 [심볼] → 모달, 입력창 자동 포커스
2. 타이핑 → 부분 일치·순서 보존 퍼지 결과 관련도순, 일치 문자 강조. 항목 = 종류 배지 + 이름 + 파일:라인 (AC-1·2)
3. ↑↓ 이동 · Enter = 정의로 이동 + 모달 닫힘 · Esc 닫힘 — **마우스 없이 완결** (AC-3)
4. 분기: 0건 → "결과 없음 — 다른 이름으로 검색해 보세요" (AC-4). 인덱싱 중이면 입력창 아래 보조 배너 "인덱싱 중 — 결과가 아직 부분적일 수 있습니다 ({done}/{total})"

### F-6: 전문 텍스트 검색 (REQ-008, SC-6)
1. **⇧⌘F** 또는 패널 [검색] 탭 → 입력창 포커스. `.*` 토글로 정규식 모드
2. Enter → 결과: 파일별 그룹, 라인 + 미리보기(일치 강조), 상단에 "N건 표시 · M 파일 검색 · T초" (AC-1)
3. 분기
   - **잘못된 정규식**: 입력창 danger 테두리 + 아래에 `⚠ 잘못된 정규식: {원인} — 위치 {n}`, **이전 결과는 흐림(40%)으로 유지**하고 "이전 결과 유지 (새 검색 미실행)" 표기. 빈 결과로 위장 금지 (AC-2)
   - 0건: "결과 없음"
   - 상한 도달: 결과 위에 경고 바 "상위 500건만 표시합니다 — 검색어를 더 구체적으로 좁혀 주세요" (AC-4)
   - 제외 대상은 코어가 결과에서 제거(AC-3) — UI는 결과를 그대로 신뢰

### F-7: 편집과 저장 (REQ-004, REQ-009, SC-3)
1. 편집 시작(Vim `i` 또는 표준 모드 타이핑) → **더티 버퍼**가 되는 즉시 3곳에 ● 표시: 창 제목 옆 · 트리의 해당 파일 행 · 상태바 경로 옆
2. 저장(`:w` 또는 ⌘S) → 실제 쓰기는 Neovim이 수행(INV-3)
3. 저장 성공 → ● 3곳에서 동시에 사라짐 + 상태바 메시지 **`✓ 저장됨 · {파일명} ({줄 수}, {크기})`** 2초 + 인덱스 칩 `최신 → 갱신 중` 전이 → 완료 시 `최신` 복귀 (REQ-009 AC-1·AC-5)
4. 저장 실패(권한 없음 등): Neovim이 자기 영역에 에러를 표시하므로 **앱은 중복 표시하지 않는다**. 더티 ●는 유지되어 "저장 안 됨"이 계속 보인다

### F-8: 입력 모드 토글 (REQ-010, SC-9)
1. 수단 2종(둘 다 필수): **편집 ▸ 입력 모드 ▸ Vim / 표준** 메뉴 항목, **⌃⌘V** 단축키 (AC-3). (툴바 세그먼트는 발견성 보강용 선택 구현)
2. 전환 즉시 상태바 좌측 세그먼트가 바뀐다 — 현재 모드는 **항상** 보인다 (AC-3)
   - Vim: `[NORMAL] Vim` (하위 모드는 Neovim 내부 모드를 그대로 반영: NORMAL/INSERT/VISUAL/COMMAND)
   - 표준: `[표준] 맥 기본 편집` (하위 모드 없음 — 모드 개념이 없다는 AC-2를 UI로도 지킨다)
3. 상태바 중앙 힌트도 모드에 따라 바뀐다: Vim `:w 저장 · gd 정의 이동 · ⌃O 뒤로` / 표준 `⌘S 저장 · ⌘B 정의 이동 · ⌘[ 뒤로`
4. 전환은 **키 해석 계층만** 바꾼다 — 버퍼·커서·undo·더티 상태는 그대로다. 전환만으로 저장되지 않으며, UI에도 저장 피드백이 뜨지 않는다 (AC-4)
5. 모드는 재시작 후 복원된다 (AC-6)

### F-9: 편집 세션 생애주기 (REQ-004 AC-1·AC-5, §6, SC-7)
`미기동 → 연결 중 → 연결됨 → 끊김 → (재기동) 연결 중`
1. **연결 중**: 에디터 영역에 카드 "편집 세션 연결 중… / 연결 전 키 입력은 전달되지 않습니다(입력 유실 방지)". 상태바 칩 = 앰버 스피너. 트리·검색은 이미 사용 가능
2. **기동 실패**(Neovim 미설치·버전 미달): 카드 "Neovim을 찾을 수 없습니다" + 설치 안내(`brew install neovim`, 필요 버전, 탐색 경로 3곳) + [다시 확인] / [읽기 전용으로 계속]. 조용한 실패 금지 (REQ-NF-005)
3. **끊김**: 에디터 영역을 흐림 처리 + 오버레이 카드 "편집 세션이 끊겼습니다 / 키 입력이 전달되지 않습니다" + **[편집 세션 재기동 ⌃⌘R]**. 상태바 좌측이 `[편집 불가] 세션 끊김`(danger)로, 세션 칩이 `끊김`으로 바뀌고 중앙에 상시 에러 메시지
   - **끊김 상태에서도 트리·심볼 검색·참조·전문 검색은 계속 동작한다**(인덱스는 편집 세션과 독립). 카드에 이를 명시해 "앱 전체가 죽은 것"으로 오인하지 않게 한다
   - 카드 문구에 "재기동하면 파일은 디스크 내용으로 다시 열립니다"를 넣어 복구 기대를 정직하게 관리

### W-2 프로젝트 열기 (REQ-001)
- **컴포넌트**: 앱 마크, 제목 "프로젝트를 여세요", 설명, [프로젝트 열기… ⌘O], **최근 프로젝트 리스트**(이름 + 경로 + 마지막 연 시각), 제외 규칙 보조 문구 / 툴바 프로젝트 팝업(전환용) / 실패 시트
- **상태**
  - 최근 0건: 리스트 블록 자체를 숨기고 [프로젝트 열기…]만
  - 최근 N건: 최대 5건, 최신순. 항목 선택 = 즉시 열기
  - 여는 중: 버튼 비활성 + 트리 스켈레톤
  - **실패(경로 없음)**: 시트 "프로젝트를 열 수 없습니다 / 경로를 찾을 수 없습니다: {경로}" [확인] — 이전 상태 유지 (AC-3)
  - **실패(권한 없음)**: 시트 "폴더에 접근할 권한이 없습니다: {경로}" [확인]
  - 최근 항목이 사라진 경로: 열기 시도 시 위 실패 시트 + 해당 항목을 목록에서 제거

### W-3 심볼 퍼지 검색 모달 (REQ-007)
- **컴포넌트**: 딤 오버레이, 입력창(자동 포커스), 부분 결과 배너(조건부), 결과 리스트(종류 배지 · 이름[일치 강조] · 파일:라인), 푸터 키 힌트(↑↓ 이동 · ⏎ 정의로 이동 · esc 닫기)
- **상태**: 입력 전(힌트) / 결과 있음(선택 행 강조, 최대 50건) / **0건**("결과 없음 — 다른 이름으로 검색해 보세요") / **인덱싱 중 보조 배너** / 로딩(200ms 이상일 때만 스피너 — 깜빡임 방지)
- **접근성**: `role="dialog" aria-modal`, 리스트 `listbox/option`, `aria-activedescendant`로 선택 추적, Tab 포커스 트랩

### W-4 정의 후보 목록 (REQ-005)
- **컴포넌트**: 커서 앵커 팝오버 — 헤더("**{이름}** 정의 {N}건 — 이동할 위치를 선택하세요"), 후보 행(종류 배지 + 시그니처 + 파일:라인), 푸터("이 이름의 참조 보기 ⇧⌘B" + 키 힌트)
- **상태**: N≥2건(목록) / 1건(팝오버 없이 즉시 이동) / **0건(팝오버 없이 상태바 에러 메시지 3초)** / 화면 가장자리에서 위·아래 자동 플립
- 긴 시그니처·경로는 한 줄 말줄임(줄바꿈 금지 — 행 높이 고정)

### W-5 참조 패널 (REQ-006)
- **컴포넌트**: 탭 헤더, 심볼 이름 + 건수(정의 N), **근사 안내 배너(상시)**, 파일별 그룹 목록(라인 + 미리보기 + [정의] 배지), 선택 항목 강조
- **상태**: 초기(심볼 미선택 — "심볼에 커서를 두고 ⇧⌘B를 누르면 참조 목록이 여기에 표시됩니다") / 로딩 / 정상 / **0건**("'{이름}' 참조 없음", 배너 유지) / 인덱싱 중(배너 아래 "인덱싱 중 — 결과가 아직 부분적일 수 있습니다")

### W-6 전문 검색 패널 (REQ-008)
- **컴포넌트**: 탭 헤더, 검색 입력 + `.*` 정규식 토글(on = accent 채움), 결과 메타("N건 표시 · M 파일 검색 · T초"), 상한 경고 바(조건부), 파일별 그룹 결과
- **상태**: 입력 전 / 로딩 / 정상 / **0건** / **정규식 에러**(danger 테두리 + 원인 문구 + 이전 결과 흐림 유지) / **상한 도달**(경고 바)

### W-7 상태바 (REQ-004·009·010·011) — 이 앱의 상태 표시 단일 면
```
[모드 세그먼트] │ [파일 경로 + 더티 ●]      [메시지 또는 모드별 힌트]      [커서 위치] │ [언어] [인덱스 칩] [편집 세션 칩]
   좌측 고정                                       중앙 가변                              우측 고정
```
- **좌: 입력 모드 세그먼트** (항상 표시 — REQ-010 AC-3)
  | 상태 | 칩 | 색 |
  |------|----|----|
  | Vim · NORMAL | `NORMAL` + `Vim` | success |
  | Vim · INSERT | `INSERT` + `Vim` | accent |
  | Vim · VISUAL | `VISUAL` + `Vim` | purple |
  | Vim · COMMAND | `COMMAND` + `Vim` | warning |
  | 표준 | `표준` + `맥 기본 편집` | accent |
  | 편집 불가 | `편집 불가` + `세션 끊김` | danger(외곽선) |
- **좌: 파일 경로** — 프로젝트 루트 기준 상대 경로, 파일명만 굵게. 폭이 좁으면 앞쪽부터 `…/` 축약. 우측에 **더티 ●**(warning, 툴팁 "더티 버퍼 — 저장되지 않은 변경")
- **중앙: 메시지 영역** — 메시지가 없으면 모드별 힌트를 표시. 메시지 3종
  - 성공(2초): `✓ 저장됨 · {파일명} ({줄 수}, {크기})`
  - 에러(3초): `✕ '{이름}' 정의를 찾을 수 없습니다`
  - 상시 에러: `⚠ 편집 세션이 끊겼습니다 — ⌃⌘R로 재기동` (끊김 동안 계속)
  - `aria-live="polite"`(성공) / `assertive`(에러)
- **우: 커서 위치 · 언어 · 인덱스 칩(W-10) · 편집 세션 칩**
  | 편집 세션 | 칩 |
  |----------|----|
  | 미기동 | 회색 점 + "편집 세션 미기동" |
  | 연결 중 | 앰버 스피너 + "편집 세션 연결 중" |
  | 연결됨 | 초록 점 + "편집 세션 연결됨" |
  | 끊김 | 빨강 점 + "편집 세션 끊김" (danger 외곽선) |
- **좁은 창(<900px)**: 힌트 숨김 → 경로 축약 → (더 좁으면) 언어·커서 위치 숨김. **모드 세그먼트와 인덱스 칩은 절대 숨기지 않는다**

### W-8 편집 세션 오버레이 (REQ-004 AC-1·AC-5, REQ-NF-005)
| 상태 | 카드 | 행동 |
|------|------|------|
| 연결 중 | ⏳ "편집 세션 연결 중…" / "연결 전 키 입력은 전달되지 않습니다(입력 유실 방지)" | 대기 |
| 기동 실패 | 🚫 "Neovim을 찾을 수 없습니다" / 설치 명령·필요 버전·탐색 경로 | [다시 확인] [읽기 전용으로 계속] |
| 끊김 | ⚠️ "편집 세션이 끊겼습니다" / "트리·심볼 검색·참조·전문 검색은 계속 사용할 수 있습니다" | **[편집 세션 재기동 ⌃⌘R]** |
- 공통: 에디터 영역만 흐림(40%) 처리하고 **트리·패널은 정상 밝기 유지**. 오버레이가 떠 있는 동안 에디터로 가는 키 입력은 전부 무시(입력 유실 방지)

### W-9 메뉴 막대 (REQ-010 AC-3, REQ-011 AC-1·AC-2)
| 메뉴 | 항목 (단축키) |
|------|--------------|
| 파일 | 프로젝트 열기…(⌘O) · 최근 프로젝트 열기 ▸ · 프로젝트 닫기(⇧⌘W) · 저장(⌘S) · 창 닫기(⌘W) |
| 편집 | 실행 취소(⌘Z) · 다시 실행(⇧⌘Z) · 오려두기/복사/붙여넣기(⌘X ⌘C ⌘V) · 전체 선택(⌘A) — **표준 모드에서만 활성** / 입력 모드 전환(⌃⌘V) · Vim 모드 · 표준 모드(현재 모드에 체크) / 편집 세션 재기동(⌃⌘R) |
| 이동 | 심볼 검색…(⌘P) · 전문 검색…(⇧⌘F) · 정의로 이동(⌘B) · 참조 보기(⇧⌘B) · 뒤로(⌘[) · 앞으로(⌘]) |
| 보기 | 파일 트리 표시(⌥⌘1) · 참조·검색 패널 표시(⌥⌘0) · 전체 화면 시작(⌃⌘F) |
| 창 / 도움말 | 최소화(⌘M) · 확대 · 도움말 |
- **키 라우팅 규칙(구현 계약)**: 앱은 **⌘를 포함한 조합만** 가로챈다. ⌃ 단독 조합(⌃O·⌃R·⌃V·⌃W…)과 모든 일반 키는 가공 없이 Neovim으로 전달된다 → REQ-011 AC-2("충돌하지 않는다")를 규칙으로 못 박는다
- Vim 모드에서 텍스트 편집 메뉴 항목을 비활성화하는 이유: Vim 모드에서는 `u`·`y`·`p`가 그 역할이며, 두 경로가 섞이면 undo 이력이 갈린다(INV-3의 "편집 단일 경로" 정신). ⌘S만 두 모드 공통 활성(실제 쓰기는 `:w` 위임)

### W-10 인덱스 상태 (REQ-009, §6 전이표 1:1)
| §6 상태 | 칩 | 진행률 |
|--------|----|-------|

## 6. 데이터 요구 (백엔드/코어 시니어 전달)

웹앱판과 달리 HTTP가 아니라 **앱 내부 함수 호출**이지만, 화면이 요구하는 필드는 동일하게 계약이 필요하다.

| 화면 | 필요 데이터 | 비고 |
|------|-----------|------|
| W-2 최근 프로젝트 | `[{name, rootPath, lastOpenedAt}]` 최신순 5건 | 재시작 후 복원 (REQ-011 AC-3) |
| 프로젝트 열기 | `open(rootPath) -> Result<Project, OpenError>`; `OpenError = notFound(path) \| noPermission(path)` | 사유별 시트 문구 분기 (AC-3) — 사유 마스킹 금지 |
| W-1 트리 | 디렉토리별 `[{name, path, isDirectory}]` 지연 로드 | 제외 목록 적용 후 결과 |
| 에디터 | `openBuffer(path)`, `isDirty(buffer) -> Bool`, `cursor -> (line, col)`, `mode -> NvimMode`, `filetype -> String` | 상태바 갱신용 — 이벤트 스트림 필요(폴링 금지) |
| 편집 세션 | `sessionState -> {notStarted, connecting, connected, lost}` + `restart()` + `neovimMissing(reason, searchedPaths, requiredVersion)` | §6 전이 그대로. 상태 변화 이벤트 필요 |
| 저장 | `save(buffer)` 완료 이벤트 `{path, lineCount, byteSize}` | 상태바 성공 메시지 문구에 사용 |
| W-10 인덱스 | `indexState -> {none, indexing(done,total), ready, updating, rescanning(done,total)}` + `stats {fileCount, symbolCount, skippedCount, lastUpdatedAt}` | 진행률은 이벤트 스트림. skippedCount = REQ-002 AC-4 |
| W-4 정의 | `definitions(name) -> [{name, kind, path, line, signature?}]` | kind = 배지 7종 |
| W-5 참조 | `references(name) -> {total, items:[{path, line, previewText, matchRanges, isDefinition}]}` 정렬(path, line) | 파일별 그룹은 UI가 수행 |

| W-6 전문 검색 | `searchText(query, regex) -> Result<{items:[{path,line,previewText,matchRanges}], total, truncated, limit:500}, RegexError(message, position)>` | 정규식 에러는 **에러로** 반환(빈 결과 금지, SC-6) |

## 11. 리더 판정 (§10 확인 요청 6건 — 2026-08-29)
PD가 올린 미결 항목에 대한 결정. 이후 구현·QA는 이 판정을 따른다.

1. **Neovim 최소 버전 = 0.9.0**. 근거: `nvim_ui_attach` 그리드 프로토콜과 msgpack RPC가 안정된 버전이고 배포판에 널리 깔려 있다. 현재 개발 환경 실측치는 0.12.5. 기동 시 버전 미달이면 REQ-004 AC-1대로 명확히 안내한다(자리표시자를 이 값으로 교체).
2. **표준 모드에서 사용자 nvim 상태줄이 `-- INSERT --`를 노출하는 것 = 수용**. INV-4(설정 비침범)를 깨면서까지 가릴 이유가 없다. **앱 상태바가 모드의 단일 권위**이며, 두 표시가 다르게 보일 수 있음을 감수한다(사용자 설정을 존중한 결과임).
3. **⌘F(파일 내 찾기) = 스코프 밖 유지**. Vim 모드는 `/`가 있고 표준 모드 대응은 REQ에 근거가 없다. 후속 후보로만 기록.
4. **수동 전체 재스캔 메뉴 = 제외**. REQ-009의 자동 재인덱싱·대량 폴백으로 충분하다.
5. **툴바 모드 세그먼트 = 구현한다**(선택 아님). AC-3의 "현재 모드 항상 표시"를 메뉴·단축키보다 직접적으로 충족하고, 프로토타입 시각 기준물에도 이미 포함돼 있다.
6. **"읽기 전용으로 계속" 버튼 = 제거**. REQ 근거가 없고 편집 불가 상태의 별도 모드를 만드는 것은 범위 확대다. (Neovim 부재 시 트리·검색만이라도 쓰게 할지는 후속 논의 대상 — 저널에 기록.)
