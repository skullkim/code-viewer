# 완료 인증 기준 — code-navigator-mac

> **소유자: 리더 단독.** 팀은 이 파일을 편집하지 않는다. 읽고 기준으로 삼으면 된다.
>
> 빌드 '완료'는 **리더가 아래를 전부 통과시키고 `BUILD_COMPLETE.md` 를 쓴 시점에만** 성립한다.
> 매트릭스·QA 리포트·작업표의 완료 문구는 *리더 인증 대기 중인 주장*이지 완료가 아니다.

## 0. 발주 전제 (넷 다 충족돼야 최종 라운드를 발주한다)

| # | 전제 | 확인 방법 | 현재 |
|---|------|----------|------|
| 1 | 게이트 그린 | `bash _workspace/gate.sh` → `GATE: PASS` | ✅ |
| 2 | `.app` 조립·실행 | 게이트 프론트 블록 | ✅ |
| 3 | **화면 잠금 해제** | `ioreg -n Root -d1 -a \| grep -A1 CGSSessionScreenIsLocked` → `<false/>` 또는 키 부재 | ❌ 사용자 조치 대기 |
| 4 | **미연결 뷰 연결** | 아래 §1 마운트 카운트 | ❌ |

3번이 없으면 라이브 E2E·디자인 충실도를 **실행할 수 없다**. 4번이 없으면 **검증할 대상이 화면에 없다** —
플레이스홀더는 클릭할 수 없다.

## 1. 마운트 카운트 (기계적 — 화면 판정의 1차 관문)

정의부를 뺀 참조 수를 센다:

```bash
for v in PlaceholderPane MainWindowView StatusBarView FileTreeView EditorGridView \
         ProjectOpenView DefinitionCandidatesView EditSessionOverlayView; do
  n=$(grep -rn "$v(" Sources/ --include="*.swift" | grep -v "struct $v" | wc -l | tr -d ' ')
  echo "$v: $n"
done
```

**합격선: `PlaceholderPane` 이 0 이고, 나머지 화면 뷰가 각각 1 이상.**

이 값이 필요한 이유: 뷰가 컴파일되고 테스트를 통과해도 **아무도 인스턴스화하지 않으면 사용자에게
도달하지 않는다**. 그리고 그 상태에서도 게이트는 초록이다. 실제로 630 테스트가 통과하는 동안
창은 회색 판 3장이었다.

⚠ 마운트 카운트는 *꽂혔는지*만 본다. *제대로 그려지는지*는 §3·§4 가 본다.

## 2. 게이트 (리더가 직접 재실행 — 팀 주장이 아니라)

```bash
bash _workspace/gate.sh
```

포함: `swift build` · `swift test --no-parallel` · 실행 테스트 수 하한 · `.app` 조립 ·
번들 실행 검증 · 번들 검사기 자체 검사 · 민감정보 스캔.

**`--no-parallel` 인 이유**: 다섯 스위트가 각자 실제 Neovim 을 띄워, 병렬에서는 같은 코드가
부하에 따라 통과하기도 실패하기도 했다(5회 중 3회 실패 → 직렬 3회 전부 통과).

여기에 **뷰 조립 방어선**이 더해져야 한다(프론트 시니어 작업):
뷰 인스턴스화 테스트 + 조립 지점 고정. 단언 대상은 **"플레이스홀더가 아니다"** 여야 한다 —
"뷰가 만들어졌다"만 단언하면 플레이스홀더가 남아 있어도 통과한다.

## 4. 디자인 충실도

`_workspace/prototype/shots/` 를 시각 기준물로, 실제 앱 스크린샷과 화면별 대조
(`scripts/screenshot-app.sh`). 레이아웃·토큰·상태·반응형.

⚠ **`02_design.md` §4.1 대비 수치는 리더가 "실제 놓이는 표면 전부의 최악값" 기준으로 갱신했다.**
구현이 문서와 다르면 먼저 문서가 낡았는지 확인한다 — 무비판적으로 02 를 기준물로 쓰면 거짓 버그를 낸다.

## 6. 증거로 인정하지 않는 것

- **"파일이 존재한다"** — 라우트 파일이 있고 등록도 됐는데 엔드포인트가 TODO 였던 사례가 있다.
- **"테스트가 전부 초록"** — 존재하는 테스트의 그린일 뿐이다. 뷰 테스트 0건인 상태에서도 630건이 초록이었다.
- **매트릭스의 `테스트 상태` PASS** — "나열된 테스트가 통과한다"는 뜻이지 화면 성립이 아니다.
- **`--self-check` 통과** — `CodeNavigatorMain.swift` 에서 `run()` **이전에 return** 한다. 창·뷰 생성을 실행하지 않는다.
- **팀의 자가 라이브 E2E·디자인 충실도 PASS** — 이 둘은 리더 인증 단계다. 팀이 돌렸으면 "팀 자가검증(리더 인증 대기)"로만 표기한다.
- **빈 명령 출력** — 그 명령이 잡을 수 있는지부터 확인한다. 리더가 `ioreg` 빈 결과를 "잠금 해제"로 오독했고,
  스크린샷 파일 크기를 "찍힘"의 증거로 삼았다(내용은 배경화면이었다).
